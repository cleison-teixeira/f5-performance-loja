# Prompt — Criar ou Revisar Testes

Crie ou revise testes que provem o comportamento, não apenas a execução do código.

Inclua:
- caminho feliz;
- permissões;
- dados ausentes;
- duplicidade e concorrência quando aplicável;
- regressão do bug;
- compatibilidade dos fluxos existentes;
- falha de banco ou API quando relevante.
