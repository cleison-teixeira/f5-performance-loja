# Checklist de Feature

## Produto

- [ ] Problema e usuário foram definidos?
- [ ] Resultado esperado foi definido?
- [ ] Regra de negócio foi aprovada?
- [ ] Critérios de aceite são verificáveis?
- [ ] A feature pertence ao módulo correto?

## Arquitetura

- [ ] Impactos em núcleo, módulos e permissões foram mapeados?
- [ ] Multiempresa, multiloja e ecossistema foram considerados?
- [ ] Existe necessidade de ADR?
- [ ] Existe necessidade de migration?
- [ ] Compatibilidade foi preservada?

## Entrega

- [ ] Feature foi dividida em partes pequenas?
- [ ] Testes foram definidos antes da homologação?
- [ ] Segurança e LGPD foram avaliadas?
- [ ] Observabilidade foi prevista?
- [ ] Documentação foi atualizada?
- [ ] Staging e rollback estão prontos?
