# Checklist de Bugfix

## Diagnóstico

- [ ] O bug foi reproduzido?
- [ ] Ambiente, usuário, loja e passos foram registrados?
- [ ] Há evidência: print, vídeo, log ou resposta da API?
- [ ] A causa raiz foi identificada?
- [ ] O impacto em fluxos relacionados foi mapeado?

## Correção

- [ ] A correção é a menor mudança segura?
- [ ] Não houve refatoração fora do escopo?
- [ ] Compatibilidade foi preservada?
- [ ] Erros e estados vazios foram tratados?

## Validação

- [ ] Foi criado teste de regressão quando aplicável?
- [ ] Testes existentes passaram?
- [ ] Build passou?
- [ ] Checklist de segurança foi aplicado?
- [ ] Staging foi validado?
- [ ] Roteiro de homologação foi entregue?
- [ ] Cleison homologou?
- [ ] Rollback está definido?
