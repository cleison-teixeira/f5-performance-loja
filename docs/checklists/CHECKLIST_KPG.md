# Checklist KPG

Ver `docs/04_KPG_KNOWLEDGE_PRESERVATION_GATE.md` (documento normativo) para a definição completa do gate. Este checklist é só o fechamento rápido — não substitui o documento normativo.

## Antes de encerrar uma investigação

- [ ] O que foi descoberto?
- [ ] Onde está documentado?
- [ ] Qual é a evidência?
- [ ] O que é fato?
- [ ] O que é inferência?
- [ ] O que continua desconhecido?
- [ ] Existe segredo no documento?
- [ ] Existe dado pessoal?
- [ ] O índice foi atualizado?
- [ ] Código/migration aponta para a documentação?
- [ ] Documento aponta para código/migration?
- [ ] Existe commit?
- [ ] Houve revisão?
- [ ] O dono do produto aprovou?
- [ ] Outra IA conseguiria reconstruir esta descoberta apenas usando o repositório?
- [ ] Estado final do KPG?
